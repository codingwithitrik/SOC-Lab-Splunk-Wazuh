SOC-Lab-Splunk-Wazuh

 ## SOC Lab – Splunk & Wazuh

This project demonstrates a mini SOC environment built using
Windows and Linux virtual machines monitored through Splunk and Wazuh.

### What I Did
- Ingested Windows & Linux logs into SIEM
- Created SPL queries to detect brute-force attacks
- Analyzed alerts and mapped them to MITRE ATT&CK
- Documented incidents and response steps

### Tools Used
Splunk, Wazuh, Windows Event Logs, Linux Logs, MITRE ATT&CK
